# Fit — Complete Fitness Tracker

Fit es una PWA para control integral de composición corporal, nutrición, entrenamiento, rutinas, objetivos y progreso.

## V1
- Peso, % grasa, masa magra y medidas
- Objetivos de peso, grasa y fuerza
- TDEE, déficit/superávit y macros
- Alimentos por gramos y porciones
- Recomendaciones según macros restantes
- Ejercicios, rutinas y sesiones
- Series, kg, reps, RIR/RPE, volumen y 1RM
- Progresión sugerida
- Gráficas y proyecciones
- PWA instalable

La app es local-first. Las estimaciones son orientativas y no sustituyen atención médica o nutricional.
